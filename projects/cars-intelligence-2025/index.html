Single-Source Star Schema (stg_Cars_Raw)

All dimensions, facts, and QA audit tables read from one parameterized Power Query staging query (pDataFolder), eliminating redundant CSV scans and ensuring full reproducibility upon cloning. 

stg_Cars_Raw (Single CSV ingestion via pDataFolder)
  ├── FactVehicle     (1,214 unique vehicles, 1:* dims)
  ├── DimCompany      (32 OEMs incl. McLaren F1 split)
  ├── DimFuel         (EV / Hybrid / PHEV / H2 / ICE)
  ├── DimEngine       (Normalized powertrain specs)
  ├── DimPriceSegment (Tiered market segmentation)
  ├── _Measures       (71 DAX measures in 6 folders)
  └── qa_*            (Audit & collision checks)

Data Quality & Natural-Key Audit Findings

Initial qa_Cars_Audit checks surfaced key collisions when using only Company + Car Name + Engine. Investigation revealed two distinct root causes resolved systematically:

  • Expanded natural key to an 11-field fingerprint covering all raw attributes so distinct trims with different pricing, horsepower, or fuel types remain cleanly separated.
  • Identified and removed 4 genuine duplicate rows (identical across all 11 fields) reducing 1,218 raw rows to 1,214 unique audited vehicles with 0 key collisions.
  • Centralized 71 DAX measures inside _Measures organized by displayFolder (_CORE, _PRICE, _PERFORMANCE, _PROFILE, _DATA_QUALITY, _SCORES), paired with materialized (Static) columns for O(1) native Top N visual filtering.

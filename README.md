# Juan Manuel Rossi — 2027 Portfolio (`jmrossi.github.io`)

Executive portfolio website for **Juan Manuel Rossi** (Business Data Analyst · Project Manager · Microsoft Fabric & Power BI), deployed via GitHub Pages at [juanma-rossi.github.io/jmrossi.github.io](https://juanma-rossi.github.io/jmrossi.github.io/).

## Highlights

- **Zero-build static architecture (`.nojekyll`):** Fast, dependency-free HTML5, CSS3, and vanilla JavaScript compatible with GitHub Pages project subpaths (all internal paths are strictly relative).
- **Unified Light Editorial + Obsidian Dark UI:** Harmonized with the **Cars Intelligence 2025** design system (`#F8FAFC` / `#FFFFFF` default light mode + `#050608` dark toggle) and bilingual **EN / ES** switcher persisted in `localStorage`.
- **Cars Intelligence 2025 Showcase:** Dedicated bilingual engineering case study (`projects/cars-intelligence-2025/index.html`) with lightbox gallery, star-schema breakdown, 5-page PBIR metrics, and a live interactive portal mirror (`projects/cars-intelligence-2025/demo.html`).
- **Print-Ready Executive Resume (`resume.html`):** Synced to the latest CV (Launch Consulting / Kaijo AI SaaS & Microsoft WICC, VML Microsoft MBR, Newton Station, PL-300 Certified, DP-600 In Progress, Talento Tech ML) with ATS-clean `@media print` styling.
